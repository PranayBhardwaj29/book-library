# 📚 My Library

A sleek and playful digital bookshelf for tracking the books you’ve read, want to read, and are currently enjoying.

Live demo: https://pranaybhardwaj29.github.io/book-library/

## ✨ Highlights

- Add books with title, author, page count, and read status
- Edit details anytime
- Remove books from your library
- Toggle between read and unread with a single click
- Clean, colorful card layout for a more enjoyable reading experience
- Simple local-library tracking without any backend setup

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

## 🚀 Run Locally

1. Clone the repository
2. Open `index.html` in your browser
3. Start managing your reading list

## 📁 Project Structure

- `index.html` — page structure
- `style.css` — visual design and responsive layout
- `script.js` — library logic, form handling, and interactions

## 💡 Why This Project?

This project is a modern take on a classic library tracker, designed to keep reading habits organized while feeling visually engaging and easy to use.

Built with a love for books and clean user experiences.
